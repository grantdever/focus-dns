# Security and privacy

## What the server exposes

- **Two addresses only:** 127.0.0.1:4861 and the tailnet address (`FOCUS_TAILNET_IP`):4861. `make_server` refuses
  any other address, including 0.0.0.0, and refuses a configured tailnet address outside 100.64.0.0/10. The
  tailnet bind uses `IP_FREEBIND`, so the service starts even before Tailscale is up.
- **Every request** must come from an address that belongs to that listener (loopback, or the Tailscale range),
  and its `Host` header must name that listener. That blocks DNS rebinding.
- **Tailnet requests** also need the `focus_token` cookie (HttpOnly, SameSite=Strict, compared in constant time),
  set once by `/login?t=<token>`. The token lives in `~/.config/focus/token` (mode 600), generated by
  `bin/install-unit`.
- **Every POST** needs a same-origin `Origin` header, which blocks cross-site form posts. Bodies over 8 KB are refused.
- **Headers:** CSP `default-src 'none'`, the one script pinned by its sha256 (`page.SCRIPT_HASH`), the Geist font
  from Google Fonts as the only external load, `form-action 'self'`, `frame-ancestors 'none'`; plus `no-store`,
  `no-referrer` and `X-Frame-Options: DENY`.
- The server logs no paths or headers, so the login token never reaches the journal.
- The cookie gives no extra powers: the page and the CLI share one code path (`focus/actions.py`), so every device
  obeys the same lock rules.

## Secrets

- The NextDNS API key lives in `~/.config/focus/nextdns.env` (mode 600). It's read when needed, sent only as the
  `X-Api-Key` header to api.nextdns.io, and never printed, logged, or written into the repo or state.
- `.gitignore` excludes `*.env`, `state.json` and `token`. Only `config/nextdns.env.example` is committed.
- Units run with `NoNewPrivileges`, `ProtectSystem=strict`, `ProtectHome=read-only`. The only writable paths are
  the state folder and the generated flip-timer drop-in. Network isn't restricted, since focus calls
  api.nextdns.io and dns.nextdns.io.

## What is kept about browsing

- At NextDNS: the log, for as long as you set (1 hour recommended), in the region you pick. Analytics counts are
  NextDNS's own.
- On the server (`usage.sqlite`, mode 600, `secure_delete` on): per-device sessions by registrable domain for 14
  days, daily counts and blocked tries for 35 days. No subdomains, IPs, URLs or raw lookups. Category hits are
  stored by category name only.

## If you fork this

- Don't commit your `nextdns.env`, state folder, or a real profile dump. Fixtures in `tests/fixtures/` should be
  trimmed shapes, not exports.
- Your NextDNS profile id isn't a secret on its own, but with it anyone can use your profile as their resolver
  and spend your lookup quota. Keep it out of public repos.
- Don't widen the bind to 0.0.0.0 or put the page behind a public tunnel. The point of Tailscale here is that the
  page has no public surface.
